# Office Joke Open

One original one-line office joke, written by a small deterministic Node program (stdlib only, no network) for the [Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232) bounty on make.fun.

## The joke

> My standing desk is stuck at its lowest setting — HR calls it 'ergonomic', I call it 'a table'.

## How to run

Requires Node 22 or later. The program writes the joke to `entry.txt` inside the output directory (`MAKEFUN_OUTPUT_DIR` if set, otherwise `/output`), with no trailing newline:

```sh
node main.ts
```

It validates the joke first: 1–200 characters, a single line, not whitespace-only.
